# MLO 法令ペイン（Office.js / Word アドイン）— 導入の手引き

作成者：MLO ／ 出典API：e-Gov 法令検索 https://laws.e-gov.go.jp/

選択（クリックでのドラッグ選択）した本文から「法令名＋条・項・号」を解析し、
e-Gov 法令API で取得した**条文をタスクペインに表示**します。クリックで e-Gov の
該当法令ページも開けます（Windows / Mac / Web 版 Word に対応）。

---

## 0. 同梱ファイル

| ファイル | 役割 |
|---|---|
| `manifest.xml` | アドイン定義（サイドロードする本体） |
| `taskpane.html` | ペインの画面 |
| `taskpane.css` | スタイル（白黒基調＋焦げ茶アクセント） |
| `taskpane.js` | 解析・取得・表示ロジック |
| `proxy-worker.js` | CORS回避用プロキシ見本（**必要時のみ**） |

`taskpane.{html,css,js}` の3点を **HTTPS** のどこかに置き、`manifest.xml` の
URL をその置き場所に書き換えて Word にサイドロードする、という流れです。

---

## 1. ホスティング（HTTPS が必須）

Office アドインは HTTPS でしか動きません。最も手軽なのは **GitHub Pages** です。

1. 新規リポジトリを作成し、`taskpane.html` / `taskpane.css` / `taskpane.js` を置く
2. リポジトリの Settings → Pages を有効化（例：`https://<user>.github.io/<repo>/`）
3. 数分後、`https://<user>.github.io/<repo>/taskpane.html` が開けることを確認

（社内サーバや任意の静的ホスティング、開発時の `https://localhost:3000` でも可）

アイコンは任意です。表示にこだわらなければ未配置でも動作します（既定アイコン表示）。
用意する場合は 16/32/80px の PNG を `assets/` に置いてください。

---

## 2. manifest.xml の書き換え

`manifest.xml` 内の **`https://YOUR-HOST`** を、1 で決めたURLの基底に**すべて**置換します。

例）`https://<user>.github.io/<repo>` に置いた場合
- `SourceLocation` → `https://<user>.github.io/<repo>/taskpane.html`
- `Taskpane.Url`   → 同上
- アイコン3つ      → `https://<user>.github.io/<repo>/assets/icon-16.png` など

> `<Id>` の GUID はそのままで構いません。複数の派生版を併用する場合のみ別GUIDにします。

---

## 3. Word へのサイドロード

**Windows（共有フォルダ方式・最も簡単）**
1. 任意の共有フォルダ（例：`\\PC名\addins`）に `manifest.xml` を置く
2. Word →［ファイル］→［オプション］→［トラスト センター］→［トラスト センターの設定］
   →［信頼できるアドイン カタログ］にそのフォルダのパスを追加し「メニューに表示」にチェック → Word再起動
3. ［ホーム］→［アドイン］→［共有フォルダー］タブ → 「MLO 法令ペイン」を追加

**Mac**
`~/Library/Containers/com.microsoft.Word/Data/Documents/wef/` に `manifest.xml` を置いて Word を再起動
→［ホーム］→［アドイン］から起動

**Web 版 Word**
［ホーム］→［アドイン］→［マイ アドイン］→［マイ アドインのアップロード］で `manifest.xml` を指定

組織全体に配るなら、管理者による **Microsoft 365 管理センターの統合アプリ（集中展開）** が確実です。

---

## 4. 使い方

1. リボンの「MLO」グループ →「法令ペインを開く」
2. 本文で「会社法第362条第4項第1号」等を**ドラッグ選択**すると、自動で解析・表示
3. 「選択箇所を解析」ボタンでも手動実行可。下部の入力欄に貼り付けて解析も可
4. 各カードの「e-Gov で開く ↗」で原典を確認

対応表記：「第」の有無／算用・全角・漢数字／枝番（◯条の2）／項・号／略称（独禁法・下請法 等）。
直前に出た法令名を引き継ぎ、「同法」「本法」にも対応します。

---

## 5. CORS でうまくいかない場合（重要）

ブラウザ／WebView から e-Gov を直接呼ぶと、CORS でブロックされる可能性があります。
カードに「取得に失敗（CORS の可能性）」と出る場合は、**プロキシ**を経由してください。

1. 同梱の `proxy-worker.js` を **Cloudflare Workers** に貼り付けてデプロイ（無料枠で可）
   - 転送先は `laws.e-gov.go.jp` のみに制限済み
2. 払い出された URL を `taskpane.js` 冒頭の設定に記入：
   ```js
   const PROXY = "https://<your-worker>.workers.dev/?url=";
   ```
3. 再ホスティング（ファイルを置き換え）して Word でペインを開き直す

> 自社のセキュリティ方針に応じて、社内に同等のプロキシを立てても構いません。

---

## 6. 仕様・制約（実務上ご確認ください）

- **VBA版との違い**：Word には「ホバー」イベントが無いため、本Office.js版は
  仕様どおり「**選択（クリック）したら表示**」です（ホバー表示は VBA版のみ可能）。
- **法令IDの解決**は e-Gov v2 `/laws`（法令名検索）に依存します。表記が一致しない／
  別名未登録の法令は特定できないことがあります（`taskpane.js` の `ALIAS` に追記可）。
- **条文取得**は e-Gov v1 条文内容取得API（XML）を使用します。
- **取得結果は現行データ依存**です。改正・施行日・経過措置等が常に最新とは限らないため、
  **最終確認は必ず原典（e-Gov）**で行ってください。
- 動作には **WebView2 を備えた新しめの Word**（Microsoft 365）を推奨します。

---

## 7. 未検証事項（正直な注記）

この環境から e-Gov へ直接アクセスできないため、**ライブAPIに対する実地テストは未了**です。
v2 `/laws` の検索パラメータ名（`law_title`）や v1 `articles` の `article` 書式など、
細部は実機での挙動差が出ることがあります。最初に主要な参照（会社法・民法・労基法など）で
動作確認し、特定法令で本文が空になる等あれば、その法令名と条番号をお知らせください。
パラメータ書式・略称辞書（`ALIAS`）を調整します。
